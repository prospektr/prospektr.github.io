Privacy Policy

Last updated: 16 November 2026

This policy covers “Six Stars Uploader”, a private tool used only by the owner of the Six Stars YouTube channel.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • The channel's own videos, upload settings and scheduling (to upload and schedule the channel's videos).
  • Public comments on the channel's own videos — commenter display name and comment text (to reply as the channel).
  • The channel's own aggregated audience statistics, such as views by country.

How it is used and stored

Data is used only to run the channel. It is processed and stored locally on the owner's own computer, is not sold, shared with third parties or used for advertising, and is not combined with other data. Comment drafts are written by a language model running locally on that computer. The access token is stored locally with restricted file permissions.

Retention and deletion

Local records of comments are kept for at most 90 days. Access can be revoked at any time at myaccount.google.com/permissions; after revocation the stored token stops working and is deleted.

Contact

Questions: via the contact e-mail on the Six Stars channel page.
